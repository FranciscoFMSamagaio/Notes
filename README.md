# Notes

Este repositório é o meu caderno pessoal de estudo e referência.

Aqui organizo documentação, exemplos práticos, comandos úteis e exercícios sobre os temas que estou a aprender. O objetivo é ter conhecimento acessível num único lugar, para consultar, rever e melhorar ao longo do tempo.

## Conteúdos

| Tema | Descrição |
|---|---|
| [Command Line](CommandLine.md) | Comandos de terminal, navegação e manipulação de ficheiros. |
| [PySpark e Delta Lake](PySpark-Delta-Lake/README.md) | Percurso de Data Engineering com documentação, código, notebooks e exercícios. |

## Como utilizar este caderno

- Consulta o índice acima para escolher um tema.
- Abre os ficheiros Markdown para estudar a teoria e os exemplos.
- Usa os notebooks e exercícios para praticar.
- Regressa aos checklists dos módulos para rever os conceitos.
